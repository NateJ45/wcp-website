# Historical planning snapshots

These `plans/` and `specs/` files are point-in-time design documents from past
build phases (dated in each filename). They record what was PLANNED, not what
exists: the code has moved on since, and these are deliberately NOT kept in
sync with it (they're exempt from the "docs match reality" rule in CLAUDE.md).

Read them for the _why_ behind a design decision; read [`../`](../) and
`site/CLAUDE.md` for the current state. Don't update these when the code
changes, and don't treat a mismatch with the code as a bug.
